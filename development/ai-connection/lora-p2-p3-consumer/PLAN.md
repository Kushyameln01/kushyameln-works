- Native baseline LoRA fc2789 / Diffusion5f880 and DATA82b pins remain distinct from distribution and runner commits.
- Immutable base; strength changes and restoration rebuild from base, never re-add to an applied feed.

- No mean I/O API, management mapping copy, two-pair composition, full-model inference, merge or Pages deploy.
- Retained original hashes and reference arrays are reused; new File loading retains its own required integrity checks.
- True whole-base hash evidence remains prior-owner evidence; newly read authentic bounded ranges are not a new whole-file hash verification.
