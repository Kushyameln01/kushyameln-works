# VR180 保存欄への案内

- 対象は ChatGPT Sites v78 / `2de572c575ee979295af539c02760d00e1b5a51e` からの UI 変更。GitHub Pages への反映は対象外。
- 目的は、利用開始時から保存工程の存在が分かり、作成後に下の保存欄へ進めること。添付の左余白の縦線をガイドとして実装する。
- 確定条件: 3 の欄を常時表示し、出力がない間はグレーアウト・操作不能。目次はタイトル下。保存の完了と動画の作成を区別する。動画処理、容量、GB 表記、対応範囲、保存時の案内を維持する。
- 変更は `static-src/vr180-studio/` の HTML/CSS/画面制御と、その配信用 hash。3 を 2 の直後に置き、一時データの清掃欄はその後へ移動する。
- 操作可否・工程案内は既存の result / operation / receipt から決める。入力変更・再作成・結果破棄では、3 を消さず作成待ちへ戻す。直接保存済みの結果を「未保存」と案内しない。
- 参照: 「ブラウザツール開発の理想状態管理と完了判定」文書版 1.0 (`page_cf84110c50fc8191973c8edd5ee62117`) の操作状態・証拠の区別、技術 Tips 本文 1.2 の第16章、ブラウザツール開発資料の失敗対処ワークフロー P0/P1/P2/P7。
- 作業選択の独立監査を実施。主担当は差分と構文を静的に確認。ユーザーの「実装だけ」の指示を継承し、動画試験やブラウザ実操作は追加していない。配備用ビルドの合格を実画面の操作確認と扱わない。
- 次の工程は、既存の配備ビルド、Sites ソース保存と公開。配備結果と版は native Sites の記録および会話の完了報告を参照する。
