# AVC field metadata compatibility

- Release: `vr180-b16-avc-field-metadata-1`, code commit `a532110ca303d8de687b75a6f71d5efcf64a9125`.
- Baseline: `80c542f15d7724d3a919804b5338a8d8b0b0d9bc` (`vr180-b15-flexible-scale-candidate-1`).
- Destination: existing GitHub Pages, main `/docs`; no Sites deployment or account configuration change.

## Reported failure and change

The supplied inspection receipt rejected a 10-byte `fiel` child under `avc1`.
This is a container-admission failure, not evidence that the browser lacks an
H.264 decoder. The receipt also reports a `tmcd` reference to track 3; that
reference is already supported by the existing metadata-only copy path.
The original 359,329,907-byte video was not supplied and has not been tested.

Accept `fiel` in AVC visual sample entries and share field validation with HEVC:
exactly two payload bytes, progressive `(1,0)` or interlaced
`(2,1)`, `(2,6)`, `(2,9)`, `(2,14)`. Record the values and interlace flag in
`videoCodecDetails`. Copy retains the original box, codec configuration,
compressed samples and sample tables. Interlaced conversion still stops before
encoding because this product does not implement deinterlacing. Timecode and
track-reference conversion restrictions also remain in force.

HEVC previously checked only the field count; it now validates the order byte
as well. Unknown combinations, malformed sizes, duplicate boxes and misplaced
`fiel` remain rejected. No additional codec decoder, universal MP4 support,
HDR conversion or timecode conversion is claimed.

Primary format reference: [Apple TN2162, field/frame information](https://developer.apple.com/library/archive/technotes/tn2162/_index.html).

## Public browser verification

The public b16 UI accepted a synthetic 512 × 256 AVC/AAC MP4 containing
progressive `fiel (1,0)`. Real UI actions and the deployed Worker completed both
metadata-only copy and WebCodecs conversion (256 × 256 per eye, legacy route).
Each downloaded MP4 and its unmodified receipt were recovered. Independent
SHA-256 checks match the complete output bytes to the corresponding receipt.

| Path | Operation ID | Revision | Output bytes | Video / audio samples |
| --- | --- | ---: | ---: | --- |
| Copy | `0b2e50f4-56fd-4dd2-943f-c9fcd77b97d9` | 2 | 33,560 | 60 / 95 |
| Convert | `38935f5e-cff9-4713-aae1-e3de3ba65f50` | 3 | 53,238 | 60 / 95 |

Copy preserves mdat positions and bytes, all original sample tables, fiel,
avcC and pasp. Both outputs decode fully through FFmpeg without errors and
preserve all 95 AAC packet payloads byte-for-byte. Conversion reports 60 decoded
frames and 60 encoded packets; its Worker job ID matches its operation ID.
Both outputs contain SBS/cropped-180 VR metadata. The UI's result-discard action
was used after recovery to release this synthetic run's temporary output.

Evidence: [independent verification](evidence/fiel-2026-11-17/public-verification.json),
[copy receipt](evidence/fiel-2026-11-17/public-copy-receipt.json),
[conversion receipt](evidence/fiel-2026-11-17/public-convert-receipt.json),
[conversion screenshot](evidence/fiel-2026-11-17/public-conversion.jpg).
Raw receipts retain `downloadRecovered: false` and `saveCompleted: false` because
the page cannot independently observe ordinary download recovery. The separate
verification record, not a modified application receipt, establishes recovery.
Generated media are reproducible from `fiel-browser.py` and the existing fixture;
no user video or private receipt is committed.

Initial local Playwright Chromium launch failed because its Unix socket was
denied; a local server was also unreachable across tool sessions. An initial
Cloud browser upload attempt did not complete. The later public run above used
the supported file chooser API and succeeded. These earlier route limitations
are not codec failures and do not describe the final result.

Original-user-video acceptance, native OS direct-save, real interlaced video
decoding and target VR-player playback remain unverified. Large-video throughput
and memory peaks are not established by this short synthetic case.
