# 前処理機能の保存用スナップショット

画像・動画の前処理をGitHub Pagesの公開ツールから外し、基本速度を観測するための保存資料です。元の公開版のファイルを `snapshot.json` のcommitから取得し、元の `docs/` 相対配置とバイト列を保持しています。LBP、位置補正、重複フレーム選択、論文系処理、旧runner・labと旧Worker登録／bundleを含みます。

このディレクトリはGitHub Pagesの配信ルート `docs/` と公開一覧の外にあります。公開GitHubリポジトリ上のソースであり、秘密情報を置ける非公開領域ではありません。旧Pages URLは削除して検証します。

このスナップショット単体は実行用アプリではありません。共通FT・Unity依存等は同一commitのリポジトリから別途復元し、当時の配信構成と合わせる必要があります。保存したbundleを現在の公開Workerへ戻す操作も自動では行いません。各ファイルのSHA-256と元Git blobを `snapshot.json` で独立照合できます。

以前の利用経路成立と総時間短縮未達の結果は `../media-production/RESULT-2026-10-17.md` を参照してください。保存は高速化成功を意味しません。再公開には目的に沿った計測と新たな検証が必要です。
