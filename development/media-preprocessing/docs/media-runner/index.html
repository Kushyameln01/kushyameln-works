画像・動画の前処理

画像の特徴と時刻をそろえ、AIやほかのツールで使えるファイルへまとめます。処理はこのブラウザで行います。

入力

初期検証版：4 MiB・1メガピクセル／フレーム・10秒・100フレームまで。初期設定では全フレームを保持します。結果のZIPは8 MiBまでです。

性能比較の設定

同じ入力で速度とメモリ使用を比較するための設定です。処理をまとめる数と、同時に保持するフレーム数を変更します。

保存するフレームを設定

省略する場合も、最初・変化したフレーム・最後と、元の時刻対応を保存します。色や文字が変わったフレームは残します。位置補正との同時利用はできません。

指定時刻はフレームの時刻との完全一致で判定します。該当フレームがなければ失敗として通知します。近い時刻への置換や、動画・音声の時間短縮は行いません。

位置補正を設定

追跡する領域を表示画像のピクセル座標で指定します。元の画像はすべて残し、判定を通った補正画像と有効領域マスクを追加します。画像1枚だけでは補正しません。

判定設定 roi-policy-v1 は実データでの汎用性能が未校正です。場面転換を自動検出しません。単色・曖昧な対応は補正を見送り、理由を記録します。

結果を保存（ZIP）

ファイルを選択してください。

結果

カラーPNG、LBP特徴、元画像との座標・動画時刻の対応、処理ログを含みます。省略したフレームも元の時刻と参照先を記録します。元ファイルは手元に保持してください。

この画面の特徴出力は通常のLBPです。論文方式の学習・特徴最適化は専用の学習・評価画面で実行できます。音声は元動画を参照します。

利用ログの受信状況

開始・完了・失敗・取消の種類、処理時間、画像サイズの区分を送ります。画像・動画の内容、ファイル名、エラー本文は送りません。

受信はまだ確認していません。

この送信セッションの累計です。保存確認は受信先の応答を確認した件数です。ログの受信状況と画像・動画の処理結果は別に表示します。ZIP作成や保存の成否は、このログの対象に含みません。
