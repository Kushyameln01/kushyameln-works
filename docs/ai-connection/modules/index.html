3. 生成条件

現在のモデル経路は6 steps・guidance 1です。seedによる乱数初期化には対応していません。

初期targetと標準正規noiseは実行側が作成します。seed指定とComfyUIの乱数の一致には対応していません。ファイル入力は対応するshapeと型を確認します。生成サイズと入力のサイズが合わない場合は理由を表示し、入力を自動で拡縮しません。

6. 作業・中間結果を保存

保持済みの中間tensor・結果とフォーム設定をまとめて保存します。生成を完了できなかった場合も、保持された部分結果を保存できます。入力媒体とモデルFileの選択は、読戻した後に選び直してください。

PNGや個別の内部tensor保存とは別に、保持中の部分結果をまとめて保存します。

対応する実モデルと実行環境が必要です。入力の読込や保存だけではモデルを実行したことにはなりません。
