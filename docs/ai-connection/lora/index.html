保存と復旧について

保存するのはSDKの実payloadとmanifestです。payloadはstreamで書き込み、すべての書込みが終わってからmanifestを保存します。管理の状態表示だけではLoRAを復元できません。

読戻しでは新しいSDKから実payloadを検査し、新しい取引として開きます。保存前のruntime handleや適用権限は復活しません。不変baseと準拠consumerは改めて接続します。
