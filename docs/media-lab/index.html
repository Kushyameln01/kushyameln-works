メディアSDKの比較・共用確認

同じ入力で処理時間を比較し、2つの処理が同じWorkerプールを共有できるかを確認します。試験中も元ファイルを保持します。

比較は各条件10回。読み込み方式はmodule/bundleを交互に、単位数は1/2/4の順序を巡回して測ります。総時間には復号・計算・PNG/ZIP出力を含み、AIとの受渡し時間は含みません。
