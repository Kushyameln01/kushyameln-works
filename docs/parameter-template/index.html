パラメータ名を指定すると、DecodeParameter TemplateからBlendTreeを生成します。処理はブラウザ内で完結します。

v2/ に続けて文字・数字・_・- を入力してください（120文字まで）。日本語も使用できます。

変換内容と出力範囲
  • Clip・BlendTree内の名前に含まれる Parameter を、入力した v2/ 以降の名前へ置換します。Smooth・Function・Proxy系、Clipのキー、表示名も対象です。
  • BlendTreeは16個の独立したアセットとして保存し、直接参照するClipを各BlendTree内に格納します。BlendTree同士は外部参照を維持します。
  • 出力先は Assets/パラメータ名 です。Binary_Root・Smooth_Rootの2つを直下に置き、他の14個は「パラメータ名_Child」フォルダに格納します。
  • 毎回新しいGUIDを発行し、表示名には付加しません。Templateの計算値・接続は保持します。
  • Controller・Expression・Prefabと、BlendTreeから参照されていないClipは含みません。UnityへのImportとVRChatでの実動作は未確認です。
