パラメータ名を指定すると、DecodeParameter TemplateからBlendTreeを生成します。処理はブラウザ内で完結します。

v2/ は必須ではありません。EyeLidLeft、Custom/EyeLidLeft、v2/EyeLidLeftなど、入力した名前をそのまま使います。文字・数字・_・- を使用でき、/ で名前空間を区切れます（各区切り1〜120文字、日本語可）。

パラメータ名を入力してください。

変換内容と出力範囲
  • 主要ParameterとBinary Parameterは、接頭辞を補わず入力名どおりに生成します。Decode・Smooth・Function・Proxy系の補助名では、既存互換のため先頭の v2/ だけを除き、その他の名前空間は保持します。Clipのキーと数値bindingも同じ名前に対応させます。
  • ファイル・フォルダ・表示名に使う名前では / を %2F として保存します。Parameter自体の名前は変えません。Windows予約名や、生成ファイル名がUTF-8で255 byteを超える場合は停止します。
  • BlendTreeを独立したアセットとして保存し、直接参照するClipを各BlendTree内に格納します。BlendTree同士は外部参照を維持します。
  • 出力先フォルダは生成結果に表示します。Binary_Root・Smooth_Rootを直下に置き、その他のBlendTreeは子フォルダに格納します。
  • 毎回新しいGUIDを発行し、表示名には付加しません。Templateの計算値・接続は保持します。
  • Controller・Expression・Prefabと、BlendTreeから参照されていないClipは含みません。UnityへのImportとVRChatでの実動作は未確認です。
