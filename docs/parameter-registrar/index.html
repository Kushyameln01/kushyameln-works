トップページGitHub・ツール

unitypackage内のすべてのClip・BlendTreeから使用パラメータ名を集め、登録用のControllerとExpressionParametersを新しく生成します。ファイルはアップロードせず、ブラウザ内で処理します。

1. パラメータ名を抽出

パッケージ内のClip・BlendTreeをすべて対象にします。ControllerやExpressionの宣言値は読み取りません。

抽出したパラメータ名
    2. 共通の生成設定

    半角英数字・_・-で1〜64文字。

    すべてFloatとして登録します。初期値（-1〜1）・保存・同期は、ここで指定する共通設定です。

    unitypackageを選択してください。

    生成結果

    unitypackageをダウンロード
    入力と出力の範囲
    • ClipのAnimator Parameterカーブと、BlendTreeの使用軸・Directの重みから名前を抽出します。外部参照先は取得しません。
    • 通常のAnimator Floatカーブに対応します。対象のClip・BlendTreeを読み取れない場合は生成を中止します。バイナリ形式などの非対応データは、Unityでテキスト形式にして書き出してください。FBX等のImport時に生成されるClipを復元する機能ではありません。
    • 入力は圧縮128 MiB・展開1 GiBまでです。1オブジェクトの処理データなどにも上限があり、超過時は対象と理由を表示します。
    • 生成するアセットは、パラメータ登録用の最小ControllerとExpressionParametersの2つです。再生用StateやMotionは含めません。既存アセットは更新しません。
    • 生成したアセットの利用にはVRChat SDKが必要です。UnityへのImportと実動作の確認は、別途Unityで行ってください。
