使いたいLayerとMotionを選び、ControllerとMA Installerへまとめます。

素材はブラウザ内で処理します。サーバーへの送信はありません。Expressionを指定すれば登録設定を固定でき、未設定の部分だけ編集します。

1. 素材を読み込む

未読込み

複数選択できます。Expression Parametersは単体の.assetでも追加できます。

    商品原本と追加FXをまとめて読み込めます。選択した構造の依存素材も必要です。展開後は1ファイル128 MiB、合計256 MiBまで対応します。

    読込み素材の一覧

    原本の準備と対応範囲

    編集・収集するController・Clip・BlendTreeを含むUnitypackageを指定してください。変更しない外部Assetは、構成を解析した後に参照の維持を選べます。同じpackageから複数の構造を選べます。原本を事前に分割する必要はありません。

    登録設定を固定する場合は、対象範囲のExpression Parametersに、登録名・型・初期値・Saved・同期を指定してください。AAPなど外部登録しない項目は記載しません。全体用を指定した場合は、その1ファイルを全体の登録設定として使います。Animatorにも同じ初期値を設定したい項目は、登録表の「Animator初期値にも反映」を選択します。

    Unityテキスト形式の構造を解析します。FBX内のAnimation抽出、Unityスクリプトの実行、Shapeの作成は含みません。編集・収集が必要な構造に不足・未対応の依存があれば、対象を示して生成を止めます。維持する外部Assetは出力packageに含まれず、導入先で必要です。

    同期LayerのMotion／Behaviour上書き、別Playableを対象とするAnimatorLayerControl、未対応の独自Behaviourは診断対象です。対応できない構造が含まれる場合は生成を止めます。

    packageは展開後1ファイル128 MiB、素材合計256 MiBまで。Unity Import・MAビルド・VRChatでの実動作は、このページの静的検査とは別に確認してください。

    2. 構成を選ぶ

    Clipの適用先Path・Component型・Property名は保持します。Controllerの統合に、対象AvatarのMesh・Transform・Prefabの添付は不要です。

    商品Prefabの設定からベースを選ぶ

    Descriptorに登録されたController・Expression・元Menuを確認できます。使用する項目を選んで採用してください。改変済みAvatarの現在の設定とは異なる場合があります。

    全体用を指定すると、ブロック別のExpression設定は適用しません。

    単独Clip・BlendTreeで既存Motionを置換

    構成を解析すると、StateのMotionとBlendTreeの子を選んで置換できます。ControllerからLayerを追加した場合、その参照Motionは原則として取り込みます。外部参照の維持を選んだMotionは対象外です。単独Motionから新しいLayer・Stateを作る機能はありません。

    3. Parameterの登録を確定する

    Expression指定済みの項目は固定されます。記載されていない項目も、その範囲では外部登録しません。必要なAnimator宣言は残ります。

    構成を選ぶと解析結果を表示します。

    不足・競合している依存素材

    同じGUIDとfileIDを持つ原本の依存素材を追加して再検査してください。編集しない外部Assetは、下の「外部Assetの参照を維持する」で個別に選択できます。GUIDだけから欠落ファイル名は確定できません。競合の場合は、読み込んだ版の内容を確認して採用元を選びます。

    外部Assetの参照を維持する

    変更しないMotion・AvatarMask・参照リソースは、Sourceへ収集せず原本の参照を維持できます。選んだGUID・fileIDのAssetが導入先に存在することが条件です。同じPathだけでは代用できません。

    Controller・State・Transitionなど、編集に必要な構造は対象外です。外部Motion内の使用Parameterは未確認になるため、該当する追加元ControllerのParameter宣言を全て保持します。外部登録は引き続きExpressionと登録表に従います。
