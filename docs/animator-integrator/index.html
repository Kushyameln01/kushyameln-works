Animator Integrator(VRCFT5)

Kushyameln Works
トップページAnimator Composer

VRCFT5向けにControllerとExpressionParametersをまとめ、Binary・Smoothの専用Layerと共通Maskを配置します。元のアセット名・GUID・内包Clipを保持し、Merged_DecodeAndSmoothフォルダーにまとめます。素材はブラウザ内で処理します。

1. 素材を読み込む

Controller・ExpressionParameters・Mask・2つのBlendTreeと、その参照素材を用意してください。

2. 統合する参照を指定

AnimatorController

上から順に統合します。先頭を統合先にし、そのファイル名・GUIDを保持します。

    ExpressionParameters

    最初に選択したExpressionを統合先にし、そのファイル名・GUIDを保持します。

      重複するLayer名

      既存Layerの重複名だけを調整してください。

      固定設定と対象Playable
      • 親フォルダー：Merged_DecodeAndSmooth
      • 既存ファイルのGUID・名前・内包構造を保持
      • 全LayerのWeight：1
      • 新設StateのWrite Defaults：ON
      • ExpressionParametersは下記の例外規則を適用

      素材を選択してください。

      入力と設定を確認してください

        生成結果

        Unitypackageを保存検証記録JSONを保存
        生成記録
        
      
        生成物の静的検査結果です。UnityへのImportと実動作は別途確認が必要です。
        
    
        
    
        入力・出力と連携API
        参照素材と元のファイルパスを含むUnitypackageを読み込みます。アップロードしたファイル自体は変更しません。出力では既存GUIDを保持するため、UnityへのImport時は同じGUIDのAssetを更新します。同名Parameterの定義が競合した場合は、該当する入力を確認してください。
        全出力をAssets/Merged_DecodeAndSmooth/配下へ配置します。その下の元の階層・ファイル名と、BlendTree内のClip・GUID・fileID・metaを保持します。統合先ControllerとExpressionの必要項目だけを更新し、Installerは生成しません。
        統括ツールからは shared/animator-integrator/client.mjs の createAnimatorIntegrator() を利用できます。画面と同じWorker・統合処理を呼び出します。
        
    
        
      
        ExpressionParametersの例外規則
        
      
        登録しないParameterも、AnimatorController内の宣言・BlendTree・Clipは保持します。
        
      
        
        
        対象Expressionへの登録設定
        
        
          
        Decode/・Function/・Proxy/で始まる名前登録しない内部計算用
        
          
        Smooth/で始まり、_Functionで終わる名前登録する同期OFF。未登録なら選択したAnimatorの型・初期値を引き継ぎ、Saved OFFで追加
        
          
        上記以外のSmooth/登録しない内部計算用
        
          
        Binaryの末尾0登録しないBlendTree側で手動設定する要素
        
          
        末尾Negative：公式値域に負の範囲がない登録しない元のParameterの値域で判定
        
          
        末尾Negative：公式値域に負の範囲がある登録するBool・同期ON
        
          
        末尾Negative：値域が未定義入力を保持型・初期値・Saved・同期を変更しない
        
          
        左右EyeLidのBinary：末尾1・2／4・8登録するBool・同期ON。初期値は1・2が0、4・8が1（0.25＋0.5＝0.75）
        
          
        その他のBinary：末尾1〜9登録するBool・同期ON。初期値0／1は保持
        
          
        AlwaysOne未登録なら追加Float・初期値1。新規追加はSaved OFF・同期OFF
        
          
        v2/EyeLidLeft・v2/EyeLidRight・v2/EyeLid登録済みの項目に適用Float・初期値0.75（Animator側も適用）
        
          
        その他のParameter入力を保持型・初期値・Saved・同期を変更しない
        
                
      
        
      
        上から優先して判定します。既存のSavedは保持します。除外対象は入力に登録済みでも出力へ含めません。Smooth/…_FunctionとAlwaysOne以外の未登録名は追加しません。
        
      
        名前は大文字・小文字を区別します。Binaryの数字は半角末尾で判定します。Negativeの値域判定と左右EyeLidのBinary規則は、v2/Name・v2.Nameと、その前に付いたスラッシュ区切りの名前空間に対応します。FloatのEyeLid初期値は表にある名前の完全一致です。
        
      
        参照：VRCFT5 Parameter範囲 · Binary Parameters
