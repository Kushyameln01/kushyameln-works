DiffusionModels

Kushyameln Works
GitHub・ツールText EncoderVAE

Hike/WASMの数値処理を、同じページのJavaScriptや明示したMessagePortから呼び出すモジュールです。モデル全体の推論・画像生成は提供していません（modelInference: false）。

利用できる処理

  • モデル情報とtensorの検査

    safetensorsのヘッダーと、公開Text Encoder・VAEのshape、意味、モデル識別を確認します。

  • Euler・固定scheduler・noise/flow計算

    固定プロファイルの6 stepとHIGH/LOWの区切り、渡された配列の数値更新をHikeで計算します。

  • Wan2.1 raw meanの正規化と復元

    公開VAEの固定profile [1,16,2,2,2] を明示的に変換します。生成sampleをposterior meanへ読み替えません。

  • 固定Q射影の部分演算

    16×5120の重みタイルをHikeで復号し、ORT WASMのGemmとHikeのbias加算へ接続します。モデルの1 step予測ではありません。

APIと接続

  • 外部API仕様

    操作、tensor契約、所有権、取消と対応範囲。

  • JavaScript API入口

    createDiffusionModels() と attachDiffusionPort() を提供します。

  • Tensorの受渡し・保存

    公開済み .wktensor 形式を使い、shape・意味・出所を照合します。

load・predict・sample は現在 NOT_READY を返します。モデル重みはこの公開資材に含めません。包括UIは操作順・待機列・入出力を扱い、数値変換はこのモジュールが担当します。
