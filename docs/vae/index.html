Kushyameln WorksText Encoder

VAE

Wan2.1 VAEで、画像tensorとlatentを変換します。選択した実行用プロファイルと同じshapeのtensorを使います。

モデル

エクスポーターで作成したmanifest.json・ONNX・conv2重みのフォルダ。

入力tensor

プロファイルと同じ枚数・寸法の画像を選びます。ファイル名順に並べ、拡縮は行いません。

NCTHW形式。画像値域は−1〜1。Encodeはraw平均latentを返し、乱数sampleとlatent正規化は行いません。Text Encoderのembeddingは入力できません。

実行用モデル一式を選んでください

実行記録と対応範囲
元BF16の値を保持してFP32で演算します。Decodeはraw出力で、色変換やclampを自動適用しません。元BF16実行や任意の動画サイズの検証とは別です。
