2 映像の見え方を確認

180°の映像と音声をそのまま保ち、VR情報を整えます。

横・縦で同じ角度密度なら、各眼が180°の画像は正方形、360°は横2：縦1です。それ以外の寸法は、角度範囲を別途確認できた正距円筒素材だけ「横・縦で異なる」を選べます。ガイドの「VR180」表記だけでは、この確認の代わりになりません。左右で縮尺が同じでも、投影や収録角度は寸法だけでは分かりません。比率保持は左右両眼の縦横を同じ倍率で縮小し、偶数画素にならない倍率は選べません。360°素材は正面180°を切り出した後の比率を保ちます。魚眼・カメラ固有メッシュ・左右別ファイルは非対応です。

ダウンロード

保存先を指定して保存するときのご案内

  • ChromeやEdgeでは、保存中に「.crswap」（CRSWAP）という一時ファイルが作られることがあります。まずこの一時ファイルへ動画データを書き込み、すべての書き込みが終わると、指定したMP4ファイルとして確定します。
  • このページに保存完了と表示されるまで、ページやブラウザを閉じたり、再読み込みしたりしないでください。書き込みが終わった後も、保存した内容の確認が続く場合があります。
  • 保存先を指定する方式では、指定したファイルへ書き込むため、ブラウザのダウンロード一覧や完了通知には表示されません。このページの保存状況で完了を確認してください。

「ダウンロード」ボタンを使う場合は、ブラウザの通常のダウンロードとして保存します。

対応範囲と記録

入力できる動画：映像がH.264またはH.265（HEVC）のMP4に対応し、音声はAACを1トラックまで扱えます。左右の映像が1ファイルに横並び・上下並びで入った正距円筒映像が対象です。横・縦で同じ角度密度なら、各眼が180°の画像は正方形、360°は横2：縦1です。横縦の角度密度が異なる素材は、正距円筒の各方向の範囲と眼順序を確認して明示設定した場合に限り扱います。

再圧縮しない作成：180°の映像にVR情報を付け、元の映像・音声を再圧縮せずに保存します。色の情報や、対応する形式のメタデータ・時間コード・トラック間の参照・チャプターも保持します。

180°への切出し変換：正面を中心に180°を切り出し、左右横並びのH.264・SDRのMP4を作成します。各眼の出力サイズは256・512・1024・2048ピクセルの正方形から選べます。対応する撮影日時や説明などのメタデータ、AAC音声の依存情報を保持します。一部の付加情報を保持できない場合は、処理結果と記録に表示します。時間コード・参照情報・チャプターなど、変換時の整合を保てない情報がある動画は、切出し変換を実行できません。

利用環境と容量：動画はお使いのブラウザ内で処理します。保存先の指定と切出し変換には、デスクトップ版Chrome・Edgeなど、必要なファイル操作・映像処理に対応したブラウザが必要です。ファイル容量に一律の上限はありませんが、保存先とブラウザの一時保存領域には十分な空き容量が必要です。処理できる容量や速度は、端末・ブラウザ・動画の構造によって異なります。

対応しない加工：魚眼映像やカメラ固有のメッシュ投影、左右別ファイル、HDR映像の切出し変換には対応していません。新しい視差の生成や、カメラ固有の補正は行いません。

特殊タグ・MP4構造の対応

同じタグでも内容や組合せによって扱いが異なります。「再圧縮しない作成」で保持できる情報と、「切出し変換」で引き継げる情報は次のとおりです。

情報・構造再圧縮しない作成切出し変換・条件
撮影情報・説明
meta / keys / ilst / data		対応するISO・QuickTimeのmdta形式を保持します。キーの順序、型、複数の値も維持します。撮影日時・タイトル・説明など、対応する記述情報を引き継ぎます。寸法・時刻・トラックIDに依存する未知の値の書換えには対応しません。
従来の付加情報
udta / mdir		対応するメタデータを保持します。すべての独自タグを保持するものではありません。対応する記述情報を引き継ぎます。保持対象外や保持量の制限で省略した情報がある場合は、画面と処理記録に表示します。
参照・チャプター・時間コード
tref / chap / chpl / tmcd / tc64		対応するチャプター・時間コードとトラック間の参照を保持します。これらの補助トラックやチャプターを伴う切出し変換は非対応です。
サンプルの配置と長さ
stsc / stsz / stz2 / mdat		複数のmdatと、stz2の4・8・16bit形式を読み取り、元の表と映像・音声を保持します。元のサンプルを読み取り、出力に合う表を作成します。出力のサイズ表はstszになる場合があります。
大きなBox・末尾まで続く媒体
64bit size / size=0 mdat		扱える数値範囲内の64bitサイズと、ファイル末尾のsize=0 mdatに対応します。末尾mdatの長さを確定します。約4.29 GBを超え、8byteのヘッダー拡張が必要な場合は、直前のfree/skipに再利用領域が必要です。再圧縮しない作成では、置換する旧moovを使える場合もあります。
媒体位置・管理情報
stco / co64 / moov		32・64bitの位置表と、先頭・末尾にあるmoovを読み取ります。元の媒体位置を保ち、更新したmoovを末尾へ置きます。出力に合う位置表を作成します。moovを先頭へ移すFast Start出力は非対応です。
表示時刻・再生時間
stts / ctts / cslg / edts / elst		受け入れ可能な時刻表と編集リストを保持します。cslgはv0かつsigned cttsと全5値が一致する形式に限ります。対応する単純な時間補正を扱います。複数編集・空白区間・静止区間・再生速度変更・任意の切詰めを含む編集リストや、一般的なcslgには対応しません。
音声の復号依存情報
sdtp / sgpd / sbgp（roll・prol）		受け入れ可能な依存情報の表を保持します。AACの順序・件数・サイズ・設定・相対時刻が同じ条件で、元の表を引き継ぎます。元映像の依存表を、新しく作った映像へ流用しません。
コーデック設定・色情報
avcC / hvcC / esds / colr 等		H.264（avc1）、H.265（hev1/hvc1）、AACと、対応する色情報を保持します。各トラックの設定は1種類に限ります。出力はH.264・SDRです。HDRの画素変換は非対応です。10bit入力の読取りやタグ保持だけで、HDRの色再現を保証するものではありません。
左右配置・VR投影
st3d / sv3d / proj / equi / 既知のSpherical V1 uuid		対応する180°正距円筒映像のVR情報を整えます。既知の旧方式は対応する情報をV2方式へ移します。左右・上下配置から左右横並びへ変換し、360°素材は正面180°を切り出します。メッシュ・魚眼・カメラ固有補正は非対応です。

対応しない構造：fMP4（moof等）と断片索引（sidx/mfra/tfra）、外部データ参照（dref/iloc）、未知のメーカー独自uuid、GoPro等の時間付き撮影情報（gpmd/camm）、一般的な複数音声・字幕、暗号化されたMP4は処理できません。回転・反転を持つtkhd行列、非正方形ピクセルのpasp、有効表示範囲のclapにも対応しません。

タグの保持と、再生機器での互換性・HDRの色再現・途中シークの品質は別です。再生先での見え方を確認してください。未対応構造を診断できても、その構造を加工できるとは限りません。

対応しない形式や処理を選んだ場合は理由を表示します。下のボタンから、入力形式・処理結果・保存状態などの処理記録を保存できます。
