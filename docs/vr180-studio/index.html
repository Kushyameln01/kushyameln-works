VR180 Studio

左右の映像を確かめて、180度動画へ。

検証中の機能です。小さな合成動画の加工・ダウンロードを確認済みです。VR再生・実写品質は未確認です。

変換の取消後に、一時ファイルが残る問題を確認しています。

1 動画を選ぶ

左右映像が1ファイルに入った、正距円筒のMP4を選んでください。

映像はこのブラウザで処理します。

サンプルで試す

2秒の合成映像。左右の文字、動く目印、確認用の音が入っています。

大きな解像度での動作確認

同じ合成素材を拡大した試験用映像です。実写素材の複雑さを再現するものではありません。

2 映像の見え方を確認

180°の映像と音声をそのまま保ち、VR情報を整えます。

各眼の寸法は180°なら正方形、360°なら横2：縦1に限ります。魚眼・カメラ固有メッシュ・左右別ファイルは、この検証版では受け付けません。

動画を選んでください。

3 出力を確認して保存

左右を並べた確認表示です。VRプレイヤーでの互換性は、再生先ごとに確認が必要です。

ダウンロード

対応範囲と記録

MP4・H.264・SDR、音声はAACを1トラックまで扱います。変換は正面を中心にした180°の切出しです。新しい視差を生成する処理や、カメラ固有の補正は行いません。変換後に途中から再生した場合の音声品質も未検証です。

実行環境の対応状況を処理時に確認します。容量・形式に対応できない場合は理由を表示します。記録はこのページから保存できます。
