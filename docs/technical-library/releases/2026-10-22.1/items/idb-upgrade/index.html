IndexedDB：schemaの更新

object storeやindexの追加・削除はupgrade transactionで扱う。計算途中状態の互換性確認とは分ける。

対象: IndexedDB 3.0 Working Draft 2025-08-13

適用条件

  • 対象版と利用するhostの契約を確認する。

判断の材料

object storeやindexの追加・削除はupgrade transactionで扱う。計算途中状態の互換性確認とは分ける。 旧版のデータを無条件に新しい計算状態として読まない。 実装への適用時は、下記の一次資料の該当節と現行版を確認してください。

限界

  • 旧版のデータを無条件に新しい計算状態として読まない。
