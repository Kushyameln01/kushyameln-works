IndexedDB：保存完了を判断する

個別requestの成功とtransaction全体の完了を区別する。保存済みの表示はtransaction completeに対応させる。

対象: IndexedDB 3.0 Working Draft 2025-08-13

適用条件

  • 対象版と利用するhostの契約を確認する。

判断の材料

個別requestの成功とtransaction全体の完了を区別する。保存済みの表示はtransaction completeに対応させる。 ブラウザの終了イベントだけに保存を依存させない。 実装への適用時は、下記の一次資料の該当節と現行版を確認してください。

限界

  • ブラウザの終了イベントだけに保存を依存させない。

根拠

  • Indexed Database API 3.0 — 2.7.1 Transaction lifecycle
