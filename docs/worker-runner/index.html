Web Worker共有基盤

JSONジョブを複数のWeb Workerへ分配し、登録タスクに応じてHike/WASMまたはJavaScriptで計算します。結果は入力順で返ります。処理するのはこのページを開いているブラウザです。ページを閉じると処理も終了します。

入力

単独ジョブはオブジェクト、複数ジョブは配列で指定します。入力例はビットに対応する重みの合計を求めます。例：masks [0,3,5]・weights [1,2,4] → [0,3,5]。

未完了は12ジョブ、同時保持する入力は論理16MiBまでです。FTの入力例は1ジョブ最大262,144要素で、他タスクの入力上限は仕様を参照してください。jobIdはジョブごとに変えてください。入力の変更は実行中の処理を取り消します。

待機中

処理件数と保持量
数値は共有基盤が管理する件数と論理byteです。ブラウザ全体の使用メモリではありません。


結果


動作の検証
同じ共有APIを別モジュールから呼びます。複数の試行を順に行うため、数分かかる場合があります。計算結果・Worker ID・計算区間を検査し、性能は観測値として記録します。
Module比較の前に取消・復帰の検査を実行してください。比較時間は投入呼出し直前から結果回収直後までです。並行計算の成立と速度の向上は別に判定します。不足する区間の判定はnullで記録します。
表示中の検証JSONを、全試行の値とともに省略せず保存します。検証結果は外部へ送信しません。別の検証を始めると表示は置き換わります。


ChatGPT・開発者向けの使い方
  1. ジョブJSONを入力し、実行を押します。
  2. 完了後、結果JSONを読みます。statusとjobId・inputRevisionを照合してください。
  3. 必要なら「すべて取消」を使い、新しいjobIdで再実行します。
共有APIは shared/compute/client.mjs の createComputePool です。submit・submitBatch・getStatus・getResult・releaseResult・cancel・disposeに対応します。登録タスクの入力形式・結果の保持方法は開発者向け説明を参照してください。ArrayBufferを使うタスクには専用の呼出し元が必要です。任意のコード文字列は実行しません。
