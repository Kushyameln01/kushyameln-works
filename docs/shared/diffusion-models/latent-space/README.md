# Wan21 posterior-mean latent space

`createLatentSpace(wasmBytes)` validates the generated registry SHA-256 and instantiates the actual Hike WASM. It exposes `normalizeRawMean(tensor)`, `restoreRawMean(tensor)`, `stats()` and `dispose()`. Numerical normalization belongs to this Diffusion module; callers supply and receive typed tensors through the API.

The supported float32 NCTHW profiles are `[1,16,2,2,2]` (128 values, `wan21-raw-f32-5x16x16`), `[1,16,1,2,2]` (64 values, `wan21-raw-f32-1x16x16`), and `[1,16,1,2,4]` (128 values, `wan21-raw-f32-1x16x32`), bound to Wan2.1 VAE SHA-256 `2fc39d31359a4b0a64f55876d8ff7fa8d780956ae2cb13463b0223e15148976b`. Raw input must have meaning `raw-posterior-mean`. The existing `requireWanRawLatent` stays F5-only; `requireWanRawLatentF1` and `requireWanRawLatentRect` are separate guards. Shape determines the exact allowlisted profile, and a supplied profileId must match. No padding or equal-count shape substitution is allowed.

Normalized output has meaning `wan21-normalized-posterior-mean:v1`. Its `normalization: 'wan21-comfy-f32-v1'` property is an optional derived descriptor. The versioned meaning persists through the existing `.wktensor` codec, which does not retain arbitrary extra properties. Restore requires that exact meaning, accepts an absent descriptor after save/readback, and rejects an incorrect descriptor when supplied. It returns `raw-posterior-mean` with a new data buffer and shape array. Generated diffusion samples are never relabelled as posterior means.

The source is [ComfyUI `comfy/latent_formats.py`](https://github.com/Comfy-Org/ComfyUI/blob/b5a432157de6b8884f81104cd02926adf4d597e4/comfy/latent_formats.py), Wan21 lines 755–783. The16 channel means and standard deviations are embedded in Hike as float32 constants. Each channel occupies eight consecutive values in F5/Rect and four in square F1. [ABI.md](ABI.md) records the dedicated profile exports and fixed arena.

Hike preserves the source operation order, with float32 rounding after each operation:

- Normalize: `difference = x - mean`, `scaled = difference * 1`, `result = scaled / std`.
- Restore: `product = x * std`, `divided = product / 1`, `result = divided + mean`.

There is no reciprocal reassociation or JavaScript arithmetic fallback. Raw zeros undergo the same channel normalization. ComfyUI's separate high-level rule that sometimes skips normalization for an entirely empty sampling latent is not silently inserted here.

The host owns disjoint 512-byte input and output arenas, copies caller data in and results out, and clears the arena after use. WASM imports are rejected. Source/WASM hashes, compiler commit and build command are recorded in `build/build-record.json`; `kernel-registry.mjs` is generated by the build. `LICENSE-Hike.txt` is the upstream compiler license. The generated compiler runtime is unused by this no-import kernel.

Build and test with the pinned toolchain described in the build record:

```sh
DIFFUSION_TOOLCHAIN=/absolute/path/to/toolchain python docs/shared/diffusion-models/latent-space/build.py
node docs/shared/diffusion-models/latent-space/test.mjs
python docs/shared/diffusion-models/latent-space/test-browser.py
node docs/shared/diffusion-models/latent-space/test-f1.mjs
python docs/shared/diffusion-models/latent-space/test-f1-browser.py
python development/ai-connection/e6/reference-f1.py
node docs/shared/diffusion-models/latent-space/test-rect.mjs
python docs/shared/diffusion-models/latent-space/test-rect-browser.py

```

The browser test needs Python Playwright and `/usr/bin/chromium`. It serves only an explicit loopback allowlist of this module and the existing tensor helpers. Tests compare all 128 outputs with an independent staged-float32 oracle and check `.wktensor` save/readback, ownership, invalid provenance, native validation, disposal and hash rejection. The roundtrip threshold was fixed at maximum absolute error `2e-6` before running the candidate. Node and Chromium measured `2.384185791015625e-7`; the 1,024-byte arena and WASM capacity stayed constant over 100 normalize/restore cycles. WASM capacity is not an OS peak-RAM measurement. Full model inference is outside these tests.

F1 tests compare all64 outputs with independent JavaScript and Python staged-f32 references and retain the same roundtrip gate. Context metadata is validated/copied without inferring a per-latent-time mapping. Separate tests load the exact retrieved G1C codec source to verify context/meaning/model save/readback; the current main codec does not gain that metadata support from this extension. After the original F1 extension, actual small manifests and saved diagnostic VAE means became available at GitHub7e091 and were received/verified. The Rect tests use those actual64/128 mean values with real Hike and independent references; the roughly499MB graph bundles remain unreceived. These are retrieved-output arithmetic and codec checks, not a repeated VAE NN run, generated-sample restoration or larger-media support. The peer's limited64 restored-mean→real VAE decode report is recorded separately in `development/ai-connection/e6/RECT-RESULT.md`.
